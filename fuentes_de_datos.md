# Fuentes de Datos Oficiales Verificadas

| Fuente / Institución | Qué información entrega | Formato de descarga / API | ¿Exige registro? |
| :--- | :--- | :--- | :--- |
| **Energía Abierta** (Comisión Nacional de Energía) | Datos del sector eléctrico, incluyendo el factor de emisión anual del Sistema Eléctrico Nacional. | CSV, Excel y API (CKAN). | **No.** Los datos son públicos y la API es abierta. |
| **Coordinador Eléctrico Nacional (CEN)** | Operación real del sistema: generación horaria por central y tecnología. | Excel (Reportes), API REST. | **Sí.** La descarga manual no pide registro, pero el uso de la API requiere crear una cuenta de desarrollador. |
| **ENERGY STAR** (EPA, EE.UU.) | Consumo eléctrico por modelo de computador (reposo, suspensión y apagado). | CSV, JSON, API (Socrata). | **No.** Es un catálogo de datos abiertos (Open Data). |
