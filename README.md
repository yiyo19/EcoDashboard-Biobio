# EcoDashboard Biobío

Plataforma regional que mide, compara y reporta el consumo eléctrico y la huella de carbono de los laboratorios de computación en instituciones del Biobío.

## Roles del Equipo
* **Roberto Acuña Campos:** Lidera la gestión de datos, cálculos lógicos, configuración del backend (automatización con GitHub Actions) y manejo de fuentes oficiales.
* **Francisca Medina Ramírez:** Lidera el diseño de la interfaz de usuario, generación de reportes mensuales, investigación de usuarios y pruebas de usabilidad.
